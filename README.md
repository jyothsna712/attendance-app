# Attendance App

A multi-user attendance management application designed to make
attendance recording, tracking, and reporting simple and organized.

## Features

- Main account with administrative control
- Multiple sub-accounts for attendance takers
- Add and manage multiple people
- Mark people as Present or Absent
- Attendance history
- Automatic attendance percentage
- Individual attendance reports
- Overall attendance dashboard
- Secure user accounts
- Android application

## Planned Technologies

- Flutter — Android application
- Python / FastAPI — Backend
- PostgreSQL — Database
- Git — Version control
- GitHub — Source code and project collaboration
